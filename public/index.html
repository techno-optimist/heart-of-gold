THE HITCHHIKER’S FIELD GUIDE
Don’t panic.
Start small.
Heart of Gold is an open-source experiment from ProjectForty2. You set a mission; a lead agent can delegate bounded subtasks, wait for the crew, and synthesize their results.
  1. Choose a mission. Start with a question, plan, critique, or written deliverable.
  2. Pick your drive. The simulator is scripted. On ProjectForty2, connect your OpenAI, Anthropic, or xAI API account for live agents. The downloaded local app can use Codex CLI.
  3. Meet the crew. Every cursor is a task. Select it to inspect its work. Branches show delegation, not shared minds.
  4. Bring it home. Read the result and save a flight receipt. You can stop a run at any time.
Experimental means experimental.
This version produces text deliverables. Hosted agents have no browser, file editing, or web research tools. They do not verify claims against the internet, merge code, or deploy projects. Review their work before using it.
An independent, affectionate nod to The Hitchhiker’s Guide to the Galaxy. No affiliation or endorsement. The towels are metaphorical.
