The Heart of Gold plugin helps you shape a crew and inspect its work inside ChatGPT or another compatible host. The plugin and the standalone website use different execution paths.

What reaches ProjectForty2

When the host calls a Heart of Gold tool, it sends the supplied mission, crew assignments, constraints, contributions, evidence links, and summaries to the ProjectForty2 MCP service. The service validates that information and returns a structured snapshot and interface. It does not independently observe your agents or request your full chat history.

Processing and storage

The plugin service processes each request in memory. It has no plugin user accounts, saved mission database, or cross-user flight history. It does not intentionally write request bodies or contribution text to application logs. Hosting and network providers can process request metadata, such as addresses, timestamps, routes, and errors, under their own practices. This is not a promise that content never leaves your chat.

Model usage and credentials

The plugin does not request an OpenAI API key, a ChatGPT password, or an OAuth token. Reasoning and any native delegation happen through the capabilities available in your host account. Host plan limits and policies apply. The plugin service itself makes no model-provider calls. The standalone website’s optional API-key connection is separate and is not required by the plugin.

Your controls

You choose what to include in the mission and reported snapshots. Keep credentials out of task text. Your host controls chat retention, plugin installation, tool permissions, and removal. Removing the plugin stops future use through that installation; manage existing conversation data through the host’s controls.

Questions and project information

Review the open-source project and its plugin documentation. Public project issues are suitable for general questions and reproducible bugs; do not post private task content or credentials there.
