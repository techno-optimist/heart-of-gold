# Bundled font licenses

Retrieved from official Google Fonts sources on 5 November 2026. The four WOFF2 files are the Latin subsets supplied by the Google Fonts CSS API, copied byte-for-byte without modification. They are self-hosted; rendering does not contact Google. All three families are licensed under the SIL Open Font License 1.1. Their complete, unmodified notices are bundled beside the fonts.

DM Sans also includes its optical-size axis. The Latin subset is intentionally small; scripts and glyphs outside it use the CSS fallback family. The source CSS uses `font-display: swap`. Preserve the original family names and include these license files when redistributing.
